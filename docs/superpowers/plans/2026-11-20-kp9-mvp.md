# kp9 MVP — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir `kp9`, un cliente HTTP de terminal con navegación estilo k9s que guarda las colecciones como JSON, resuelve entornos, variables y auth, ejecuta requests, guarda un historial con datos sensibles ocultos e importa desde Postman v2.1.

**Architecture:** El núcleo no depende de la interfaz y se prueba con pytest. Lo forman `model` → `store` → `secrets`/`redact` → `resolve` → `httpclient` → `auth` → `history` → `importer` → `runner`. `runner` orquesta el envío completo: resolver, autenticar, enviar y registrar. La TUI en Textual es una capa delgada sobre `store`, `runner` e `history`. Tiene una pila de vistas, una barra superior, breadcrumbs y una línea de comando/filtro, y se prueba con `App.run_test()` + `Pilot`. La CLI en Typer expone `kp9` (abre la TUI), `kp9 init` y `kp9 import`.

**Tech Stack:** Python 3.11+, uv, Textual, httpx (async), pydantic v2, sqlite3, watchfiles, Typer; pytest, pytest-asyncio, respx, ruff, mypy.

**Spec:** `docs/superpowers/specs/2026-11-19-kp9-design.md`

## Global Constraints

- Python `>=3.11`, gestionado con **uv**, layout `src/kp9/`, comando instalado `kp9` (`uv tool install --editable .`).
- Todo el workspace es **JSON** (nunca YAML). Todos los nodos admiten `"description"`.
- Nombres de archivo y directorio = slugs; el nombre visible vive en `name`.
- Carpeta local `.kp9/` (`secrets.json`, `history.db`), agregada a `.gitignore` por `kp9 init`.
- Timeout por defecto **30 s**, configurable con `timeout` en `workspace.json`.
- Headers siempre redactados en historial: `Authorization`, `Cookie`, `Set-Cookie`, `X-Api-Key` + lista `redactHeaders` de `workspace.json`. Además se redacta cualquier valor de secreto presente en URL, headers o body.
- Máscara de secretos: `••••`.
- Entorno protegido **solo** con `"protected": true` (opt-in). Con entorno protegido, la barra superior va en rojo y se pide confirmación para todo método que no sea GET/HEAD/OPTIONS.
- Precedencia de variables (decidido 2026-11-21, como Postman): **entorno activo > carpeta(s) (interna→externa) > colección > grupo**. Auth: **request > carpeta(s) > colección > grupo**. `auth: inherit` (default) sube la jerarquía; si no encuentra auth, usa `none`.
- Variable sin valor tras resolver → no se envía; mensaje `{{sku}} no definida en qa`.
- Edición con `$EDITOR` (fallback `vi`).
- Textos de la UI en español.
- Sin CI ni releases; los checks (`pytest`, `ruff`, `mypy`) se corren localmente.
- **Desviaciones decididas en este plan** (la spec no las resolvía):
  - La spec asigna `e` tanto a "env" (4.1) como a "editar" (4.4). Aquí `e` = editar y **`E` (Shift-e) = vista de entornos**.
  - `workspace.json` acepta un `defaultEnv` opcional para elegir el entorno inicial. Si falta, se usa el primero en orden alfabético.

## Review Focus

1. **Colecciones Postman con nombres repetidos, o con un request llamado "Folder"/"Collection".** Nunca se sobrescribe un archivo, y el request no se confunde con `folder.json`/`collection.json` (Task 2 `unique_path`, Task 8).
2. **Respuestas que no son texto UTF-8: binarias, con charset desconocido o de más de 200 KB.** Se muestran sin romper la TUI: binario como placeholder y texto largo truncado en pantalla. `y` copia el body completo (Task 5, Task 12).
3. **Secretos transformados: codificados en la URL, dentro del body JSON o repetidos en el body de error del token endpoint. También valores de secreto vacíos.** El historial nunca guarda el secreto, y un secreto vacío no destroza el texto (Task 3, Task 7, Task 10).
4. **Variables que referencian otras variables, incluidas referencias circulares.** Se resuelven en cadena o fallan con `referencia circular: a → b → a`; nunca `RecursionError` ni cuelgue (Task 4).
5. **Workspace sin `environments/`, sin `secrets.json` o con el entorno activo borrado desde fuera.** La app abre igual y enviar muestra `… no definida (sin entorno activo)` en vez de fallar (Task 3, Task 11, Task 12).

```python
"""Modelos del dominio de kp9 (archivos JSON del workspace)."""

from __future__ import annotations

from typing import Annotated, Any, Literal

from pydantic import BaseModel, ConfigDict, Field


class _Base(BaseModel):
    model_config = ConfigDict(extra="forbid", populate_by_name=True)


class AuthInherit(_Base):
    type: Literal["inherit"] = "inherit"


class AuthNone(_Base):
    type: Literal["none"] = "none"


class AuthBearer(_Base):
    type: Literal["bearer"] = "bearer"
    token: str


class AuthBasic(_Base):
    type: Literal["basic"] = "basic"
    username: str
    password: str


class AuthApiKey(_Base):
    type: Literal["apikey"] = "apikey"
    key: str
    value: str
    in_: Literal["header", "query"] = Field(default="header", alias="in")


class AuthOAuth2CC(_Base):
    type: Literal["oauth2-cc"] = "oauth2-cc"
    tokenUrl: str
    clientId: str
    clientSecret: str
    scopes: list[str] = Field(default_factory=list)


Auth = Annotated[
    AuthInherit | AuthNone | AuthBearer | AuthBasic | AuthApiKey | AuthOAuth2CC,
    Field(discriminator="type"),
]

BodyType = Literal["none", "json", "text", "form-urlencoded", "multipart"]
HttpMethod = Literal["GET", "POST", "PUT", "PATCH", "DELETE", "HEAD", "OPTIONS"]


class Body(_Base):
    type: BodyType = "none"
    content: Any = None


class Request(_Base):
    name: str
    description: str = ""
    method: HttpMethod = "GET"
    url: str
    params: dict[str, str] = Field(default_factory=dict)
    headers: dict[str, str] = Field(default_factory=dict)
    body: Body = Field(default_factory=Body)
    auth: Auth = Field(default_factory=AuthInherit)


class NodeMeta(_Base):
    name: str
    description: str = ""
    auth: Auth | None = None
    variables: dict[str, str] = Field(default_factory=dict)


class GroupMeta(NodeMeta):
    pass


class CollectionMeta(NodeMeta):
    baseUrl: str | None = None


class FolderMeta(NodeMeta):
    pass


class SecretRef(_Base):
    secret: Literal[True]


class Environment(_Base):
    name: str
    description: str = ""
    protected: bool = False
    variables: dict[str, str | SecretRef] = Field(default_factory=dict)


class WorkspaceConfig(_Base):
    name: str
    description: str = ""
    defaultGroup: str | None = None
    defaultEnv: str | None = None
    timeout: float = 30.0
    redactHeaders: list[str] = Field(default_factory=list)


def dump(model: BaseModel) -> dict[str, Any]:
    """Serializa un modelo tal como se escribe en disco."""
    return model.model_dump(by_alias=True, exclude_none=True, mode="json")
```

```python
def test_slugify_handles_accents_and_symbols():
    assert slugify("Agregar al Carrito ñ!") == "agregar-al-carrito-n"
    assert slugify("   ") == "item"


def test_unique_path_appends_suffix_on_collision(tmp_path):
    (tmp_path / "ver.json").write_text("{}")
    assert unique_path(tmp_path, "Ver", ".json").name == "ver-2.json"
    (tmp_path / "ver-2.json").write_text("{}")
    assert unique_path(tmp_path, "Ver", ".json").name == "ver-3.json"


def test_unique_path_never_returns_meta_file_name(tmp_path):
    assert unique_path(tmp_path, "Folder", ".json").name == "folder-2.json"
    assert unique_path(tmp_path, "Collection", ".json").name == "collection-2.json"
    assert unique_path(tmp_path, "Group", ".json").name == "group-2.json"


def test_load_workspace_builds_tree(sample_ws):
    ws = load_workspace(sample_ws)
    assert ws.config.name == "mis-apis"
    assert sorted(ws.environments) == ["prod", "qa"]
    assert ws.env_files["qa"] == sample_ws / "environments" / "qa.json"
    [group] = ws.groups
    assert (group.kind, group.name) == ("group", "Pagos")
    [col] = group.children
    assert (col.kind, col.name) == ("collection", "Checkout API")
    assert [r.name for r in col.requests] == ["Buscar"]
    [folder] = col.children
    assert (folder.kind, folder.name) == ("folder", "carrito")
    assert [r.name for r in folder.requests] == ["Agregar al carrito", "Ver carrito"]
```

```python
"""Carga y escritura del workspace kp9 en disco."""

from __future__ import annotations

import json
import re
import unicodedata
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, Literal, TypeVar

from pydantic import BaseModel, ValidationError

from kp9.model import (
    CollectionMeta,
    Environment,
    FolderMeta,
    GroupMeta,
    NodeMeta,
    Request,
    WorkspaceConfig,
    dump,
)

WORKSPACE_FILE = "workspace.json"
LOCAL_DIR = ".kp9"
ENVIRONMENTS_DIR = "environments"
GROUPS_DIR = "groups"
GROUP_FILE = "group.json"
COLLECTION_FILE = "collection.json"
FOLDER_FILE = "folder.json"
META_FILES = frozenset({GROUP_FILE, COLLECTION_FILE, FOLDER_FILE})

Kind = Literal["group", "collection", "folder"]
_META: dict[Kind, tuple[str, type[NodeMeta]]] = {
    "group": (GROUP_FILE, GroupMeta),
    "collection": (COLLECTION_FILE, CollectionMeta),
    "folder": (FOLDER_FILE, FolderMeta),
}
_CHILD_KIND: dict[Kind, Kind] = {"group": "collection", "collection": "folder", "folder": "folder"}
_META_MODELS: dict[str, type[BaseModel]] = {
    GROUP_FILE: GroupMeta,
    COLLECTION_FILE: CollectionMeta,
    FOLDER_FILE: FolderMeta,
}

M = TypeVar("M", bound=BaseModel)


class WorkspaceNotFound(Exception):
    """No hay un workspace.json válido."""


@dataclass
class RequestNode:
    path: Path
    request: Request | None
    error: str | None
    chain: list[NodeMeta]

    @property
    def name(self) -> str:
        return self.request.name if self.request else self.path.stem


@dataclass
class ContainerNode:
    kind: Kind
    path: Path
    meta: NodeMeta | None
    error: str | None
    children: list[ContainerNode] = field(default_factory=list)
    requests: list[RequestNode] = field(default_factory=list)

    @property
    def name(self) -> str:
        return self.meta.name if self.meta else self.path.name

    @property
    def meta_file(self) -> Path:
        return self.path / _META[self.kind][0]


@dataclass
class Workspace:
    root: Path
    config: WorkspaceConfig
    groups: list[ContainerNode] = field(default_factory=list)
    environments: dict[str, Environment] = field(default_factory=dict)
    env_files: dict[str, Path] = field(default_factory=dict)
    errors: list[str] = field(default_factory=list)
    index: dict[Path, ContainerNode | RequestNode] = field(default_factory=dict)

    def node_at(self, path: Path) -> ContainerNode | RequestNode | None:
        return self.index.get(path)


def slugify(name: str) -> str:
    ascii_name = unicodedata.normalize("NFKD", name).encode("ascii", "ignore").decode()
    slug = re.sub(r"[^a-z0-9]+", "-", ascii_name.lower()).strip("-")
    return slug or "item"


def unique_path(directory: Path, name: str, suffix: str = "") -> Path:
    """Ruta libre `<slug><suffix>`; nunca devuelve un archivo meta ni uno existente."""
    base = slugify(name)
    candidate = directory / f"{base}{suffix}"
    n = 2
    while candidate.exists() or candidate.name in META_FILES:
        candidate = directory / f"{base}-{n}{suffix}"
        n += 1
    return candidate


def read_model(path: Path, cls: type[M]) -> tuple[M | None, str | None]:
    try:
        raw = path.read_text(encoding="utf-8")
    except OSError as exc:
        return None, f"{path}: {exc.strerror}"
    try:
        data = json.loads(raw)
    except json.JSONDecodeError as exc:
        return None, f"{path}:{exc.lineno}:{exc.colno}: {exc.msg}"
    try:
        return cls.model_validate(data), None
    except ValidationError as exc:
        first = exc.errors()[0]
        loc = ".".join(str(part) for part in first["loc"]) or "<raíz>"
        return None, f"{path}: {loc}: {first['msg']}"


def write_json(path: Path, data: BaseModel | dict[str, Any]) -> None:
    payload = dump(data) if isinstance(data, BaseModel) else data
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(payload, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")


def load_workspace(root: Path) -> Workspace:
    root = root.resolve()
    config, error = read_model(root / WORKSPACE_FILE, WorkspaceConfig)
    if config is None:
        raise WorkspaceNotFound(error or f"{root / WORKSPACE_FILE}: inválido")
    ws = Workspace(root=root, config=config)
    env_dir = root / ENVIRONMENTS_DIR
    if env_dir.is_dir():
        for path in sorted(env_dir.glob("*.json")):
            env, env_error = read_model(path, Environment)
            if env is None:
                ws.errors.append(env_error or str(path))
                continue
            ws.environments[env.name] = env
            ws.env_files[env.name] = path
    groups_dir = root / GROUPS_DIR
    if groups_dir.is_dir():
        for directory in sorted(p for p in groups_dir.iterdir() if p.is_dir()):
            if not directory.name.startswith("."):
                ws.groups.append(_load_container(ws, directory, "group", []))
    return ws


def _load_container(ws: Workspace, directory: Path, kind: Kind, chain: list[NodeMeta]) -> ContainerNode:
    filename, cls = _META[kind]
    meta_path = directory / filename
    meta: NodeMeta | None
    error: str | None
    if meta_path.exists():
        meta, error = read_model(meta_path, cls)
    elif kind == "folder":
        meta, error = FolderMeta(name=directory.name), None
    else:
        meta, error = None, f"{meta_path}: archivo faltante"
    if error:
        ws.errors.append(error)
    node = ContainerNode(kind=kind, path=directory, meta=meta, error=error)
    sub_chain = chain + ([meta] if meta else [])
    for path in sorted(directory.iterdir()):
        if path.name.startswith("."):
            continue
        if path.is_dir():
            node.children.append(_load_container(ws, path, _CHILD_KIND[kind], sub_chain))
        elif path.suffix == ".json" and path.name not in META_FILES and kind != "group":
            request, req_error = read_model(path, Request)
            if req_error:
                ws.errors.append(req_error)
            request_node = RequestNode(path=path, request=request, error=req_error, chain=sub_chain)
            node.requests.append(request_node)
            ws.index[path] = request_node
    ws.index[directory] = node
    return node


def init_workspace(root: Path, name: str) -> Path:
    root = root.resolve()
    config_path = root / WORKSPACE_FILE
    if config_path.exists():
        raise FileExistsError(f"ya existe un workspace en {root}")
    for sub in (ENVIRONMENTS_DIR, GROUPS_DIR, LOCAL_DIR):
        (root / sub).mkdir(parents=True, exist_ok=True)
    write_json(config_path, WorkspaceConfig(name=name))
    gitignore = root / ".gitignore"
    entry = f"{LOCAL_DIR}/"
    lines = gitignore.read_text(encoding="utf-8").splitlines() if gitignore.exists() else []
    if entry not in lines:
        lines.append(entry)
        gitignore.write_text("\n".join(lines) + "\n", encoding="utf-8")
    return root


def find_workspace_root(start: Path) -> Path:
    start = start.resolve()
    for directory in (start, *start.parents):
        if (directory / WORKSPACE_FILE).is_file():
            return directory
    raise WorkspaceNotFound(
        f"No se encontró {WORKSPACE_FILE} en {start} ni en sus carpetas padre. "
        "Crea uno con `kp9 init`."
    )


def count_requests(node: ContainerNode) -> int:
    return len(node.requests) + sum(count_requests(child) for child in node.children)


def group_dir_of(root: Path, path: Path) -> Path | None:
    groups = root / GROUPS_DIR
    try:
        rel = path.relative_to(groups)
    except ValueError:
        return None
    return groups / rel.parts[0] if rel.parts else None


def model_for_file(root: Path, path: Path) -> type[BaseModel]:
    if path == root / WORKSPACE_FILE:
        return WorkspaceConfig
    if path.parent == root / ENVIRONMENTS_DIR:
        return Environment
    if path.name in _META_MODELS:
        return _META_MODELS[path.name]
    return Request
```

```python
"""Valores secretos locales (.kp9/secrets.json) y referencias $ENV:."""

from __future__ import annotations

import json
from collections.abc import Mapping
from pathlib import Path

from kp9.model import Environment, SecretRef
from kp9.store import LOCAL_DIR

ENV_PREFIX = "$ENV:"
Secrets = dict[str, dict[str, str]]


class SecretsError(Exception):
    """secrets.json no se puede leer."""


def secrets_path(root: Path) -> Path:
    return root / LOCAL_DIR / "secrets.json"


def load_secrets(root: Path) -> Secrets:
    path = secrets_path(root)
    if not path.exists():
        return {}
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except json.JSONDecodeError as exc:
        raise SecretsError(f"{path}:{exc.lineno}:{exc.colno}: {exc.msg}") from exc
    if not isinstance(data, dict):
        raise SecretsError(f"{path}: se esperaba un objeto JSON")
    return {
        str(env): {str(k): str(v) for k, v in values.items()}
        for env, values in data.items()
        if isinstance(values, dict)
    }


def save_secrets(root: Path, data: Secrets) -> None:
    path = secrets_path(root)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(data, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")
    path.chmod(0o600)


def _lookup(
    env: Environment, name: str, value: str | SecretRef, secrets: Secrets, environ: Mapping[str, str]
) -> tuple[str | None, bool]:
    """Devuelve (valor, es_sensible)."""
    if isinstance(value, SecretRef):
        return secrets.get(env.name, {}).get(name), True
    if value.startswith(ENV_PREFIX):
        return environ.get(value[len(ENV_PREFIX) :]), True
    return value, False


def env_values(env: Environment | None, secrets: Secrets, environ: Mapping[str, str]) -> dict[str, str]:
    if env is None:
        return {}
    out: dict[str, str] = {}
    for name, raw in env.variables.items():
        value, _ = _lookup(env, name, raw, secrets, environ)
        if value is not None:
            out[name] = value
    return out


def sensitive_values(env: Environment | None, secrets: Secrets, environ: Mapping[str, str]) -> list[str]:
    if env is None:
        return []
    out: list[str] = []
    for name, raw in env.variables.items():
        value, sensitive = _lookup(env, name, raw, secrets, environ)
        if sensitive and value:
            out.append(value)
    return out
```

```python
"""Redacción de datos sensibles antes de persistir."""

from __future__ import annotations

from collections.abc import Iterable, Mapping
from typing import Any
from urllib.parse import quote, quote_plus

MASK = "••••"
DEFAULT_SENSITIVE_HEADERS = ("authorization", "cookie", "set-cookie", "x-api-key")

HeadersLike = Mapping[str, str] | Iterable[tuple[str, str]]


class Redactor:
    def __init__(self, secrets: Iterable[str] = (), extra_headers: Iterable[str] = ()) -> None:
        variants: set[str] = set()
        for secret in secrets:
            if secret:
                variants.update({secret, quote(secret, safe=""), quote_plus(secret, safe="")})
        self._secrets = sorted(variants, key=len, reverse=True)
        self._headers = {h.lower() for h in (*DEFAULT_SENSITIVE_HEADERS, *extra_headers)}

    def text(self, value: str) -> str:
        for secret in self._secrets:
            value = value.replace(secret, MASK)
        return value

    def headers(self, headers: HeadersLike) -> list[tuple[str, str]]:
        items = headers.items() if isinstance(headers, Mapping) else headers
        return [(k, MASK if k.lower() in self._headers else self.text(v)) for k, v in items]

    def value(self, obj: Any) -> Any:
        if isinstance(obj, str):
            return self.text(obj)
        if isinstance(obj, dict):
            return {self.text(str(k)): self.value(v) for k, v in obj.items()}
        if isinstance(obj, list | tuple):
            return [self.value(v) for v in obj]
        return obj
```

```python
"""Fusión de capas y sustitución de {{variables}}. Puro: sin IO."""

from __future__ import annotations

import re
from collections.abc import Mapping
from dataclasses import dataclass
from typing import Any

from kp9.model import Auth, AuthInherit, AuthNone, Body, CollectionMeta, NodeMeta, Request

_VAR = re.compile(r"\{\{\s*([^{}\s]+)\s*\}\}")


class ResolveError(Exception):
    def __init__(self, missing: list[str], env_name: str | None, cycle: list[str] | None = None) -> None:
        self.missing = missing
        self.env_name = env_name
        self.cycle = cycle
        super().__init__(self._message())

    def _message(self) -> str:
        if self.cycle:
            return "referencia circular: " + " → ".join(self.cycle)
        names = ", ".join("{{" + name + "}}" for name in self.missing)
        verb = "no definida" if len(self.missing) == 1 else "no definidas"
        where = f"en {self.env_name}" if self.env_name else "(sin entorno activo)"
        return f"{names} {verb} {where}"


class _Cycle(Exception):
    def __init__(self, path: list[str]) -> None:
        super().__init__(" → ".join(path))
        self.path = path


@dataclass(frozen=True)
class ResolvedRequest:
    method: str
    url: str
    params: dict[str, str]
    headers: dict[str, str]
    body: Body
    auth: Auth


def merge_variables(chain: list[NodeMeta], env_vars: Mapping[str, str]) -> dict[str, str]:
    """Entorno < grupo < colección < carpetas (externa→interna)."""
    merged = dict(env_vars)
    for meta in chain:
        if isinstance(meta, CollectionMeta) and meta.baseUrl is not None:
            merged["baseUrl"] = meta.baseUrl
        merged.update(meta.variables)
    return merged


def effective_auth(request: Request, chain: list[NodeMeta]) -> Auth:
    if not isinstance(request.auth, AuthInherit):
        return request.auth
    for meta in reversed(chain):
        if meta.auth is not None and not isinstance(meta.auth, AuthInherit):
            return meta.auth
    return AuthNone()


class _Substitution:
    def __init__(self, variables: Mapping[str, str]) -> None:
        self.variables = variables
        self.missing: list[str] = []

    def text(self, value: str, stack: tuple[str, ...] = ()) -> str:
        def replace(match: re.Match[str]) -> str:
            name = match.group(1)
            if name in stack:
                raise _Cycle([*stack, name])
            if name not in self.variables:
                if name not in self.missing:
                    self.missing.append(name)
                return match.group(0)
            return self.text(self.variables[name], (*stack, name))

        return _VAR.sub(replace, value)

    def value(self, obj: Any) -> Any:
        if isinstance(obj, str):
            return self.text(obj)
        if isinstance(obj, dict):
            return {self.text(str(k)): self.value(v) for k, v in obj.items()}
        if isinstance(obj, list):
            return [self.value(v) for v in obj]
        return obj


def _substitute_auth(auth: Auth, sub: _Substitution) -> Auth:
    data = auth.model_dump(by_alias=True)
    resolved = {k: (v if k == "type" else sub.value(v)) for k, v in data.items()}
    return type(auth).model_validate(resolved)


def resolve(
    request: Request,
    chain: list[NodeMeta],
    env_vars: Mapping[str, str],
    env_name: str | None,
) -> ResolvedRequest:
    sub = _Substitution(merge_variables(chain, env_vars))
    try:
        url = sub.text(request.url)
        params = {sub.text(k): sub.text(v) for k, v in request.params.items()}
        headers = {sub.text(k): sub.text(v) for k, v in request.headers.items()}
        body = Body(type=request.body.type, content=sub.value(request.body.content))
        auth = _substitute_auth(effective_auth(request, chain), sub)
    except _Cycle as cycle:
        raise ResolveError([], env_name, cycle=cycle.path) from None
    if sub.missing:
        raise ResolveError(sub.missing, env_name)
    return ResolvedRequest(request.method, url, params, headers, body, auth)
```

```python
"""Ejecución HTTP con httpx y representación de la respuesta."""

from __future__ import annotations

import json
import re
import shlex
import ssl
import time
from collections.abc import Mapping
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Literal
from urllib.parse import urlencode

import httpx

from kp9.model import Body
from kp9.resolve import ResolvedRequest

FailureKind = Literal["timeout", "network", "tls", "body"]
_CHARSET = re.compile(r"charset=([\w.:-]+)", re.IGNORECASE)
_TEXT_TYPES = ("text/", "json", "xml", "javascript", "x-www-form-urlencoded")


class RequestFailed(Exception):
    def __init__(self, kind: FailureKind, message: str) -> None:
        super().__init__(message)
        self.kind: FailureKind = kind


@dataclass(frozen=True)
class Response:
    status: int
    reason: str
    headers: list[tuple[str, str]]
    body: bytes
    elapsed_ms: float
    encoding: str | None = None

    @property
    def size(self) -> int:
        return len(self.body)

    def header(self, name: str) -> str | None:
        lname = name.lower()
        return next((v for k, v in self.headers if k.lower() == lname), None)

    @property
    def content_type(self) -> str:
        return (self.header("content-type") or "").lower()

    @property
    def is_json(self) -> bool:
        return "json" in self.content_type

    @property
    def is_binary(self) -> bool:
        if any(marker in self.content_type for marker in _TEXT_TYPES):
            return False
        return b"\x00" in self.body[:1024]

    def text(self) -> str:
        match = _CHARSET.search(self.content_type)
        encoding = self.encoding or (match.group(1) if match else None) or "utf-8"
        try:
            return self.body.decode(encoding, errors="replace")
        except LookupError:
            return self.body.decode("utf-8", errors="replace")

    def pretty(self) -> str:
        if self.is_binary:
            return f"‹contenido binario, {self.size} bytes›"
        text = self.text()
        try:
            return json.dumps(json.loads(text), indent=2, ensure_ascii=False)
        except ValueError:
            return text


def full_url(req: ResolvedRequest) -> str:
    if not req.params:
        return req.url
    separator = "&" if "?" in req.url else "?"
    return f"{req.url}{separator}{urlencode(req.params)}"


def _mapping(body: Body) -> Mapping[str, Any]:
    if body.content is None:
        return {}
    if not isinstance(body.content, dict):
        raise RequestFailed("body", f"el body {body.type} debe ser un objeto JSON")
    return body.content


def _multipart(body: Body) -> list[tuple[str, tuple[str | None, bytes | str]]]:
    files: list[tuple[str, tuple[str | None, bytes | str]]] = []
    for key, value in _mapping(body).items():
        text = str(value)
        if text.startswith("@"):
            path = Path(text[1:]).expanduser()
            try:
                files.append((key, (path.name, path.read_bytes())))
            except OSError as exc:
                raise RequestFailed("body", f"no se pudo leer {path}: {exc.strerror}") from exc
        else:
            files.append((key, (None, text)))
    return files


def _body_kwargs(body: Body) -> dict[str, Any]:
    if body.type == "json":
        return {"json": body.content}
    if body.type == "text":
        return {"content": ("" if body.content is None else str(body.content)).encode("utf-8")}
    if body.type == "form-urlencoded":
        return {"data": {k: str(v) for k, v in _mapping(body).items()}}
    if body.type == "multipart":
        return {"files": _multipart(body)}
    return {}


def _is_tls(exc: Exception) -> bool:
    cause = exc.__cause__ or exc.__context__
    message = str(exc).lower()
    return isinstance(cause, ssl.SSLError) or "ssl" in message or "certificate" in message


async def send(req: ResolvedRequest, client: httpx.AsyncClient, timeout: float) -> Response:
    kwargs = _body_kwargs(req.body)
    try:
        request = client.build_request(
            req.method,
            req.url,
            params=req.params or None,
            headers=req.headers,
            timeout=timeout,
            **kwargs,
        )
        started = time.perf_counter()
        raw = await client.send(request)
        elapsed = (time.perf_counter() - started) * 1000
    except httpx.TimeoutException as exc:
        raise RequestFailed("timeout", f"timeout tras {timeout:g} s") from exc
    except httpx.ConnectError as exc:
        kind: FailureKind = "tls" if _is_tls(exc) else "network"
        raise RequestFailed(kind, str(exc) or type(exc).__name__) from exc
    except (httpx.HTTPError, httpx.InvalidURL) as exc:
        raise RequestFailed("network", str(exc) or type(exc).__name__) from exc
    return Response(
        status=raw.status_code,
        reason=raw.reason_phrase,
        headers=list(raw.headers.multi_items()),
        body=raw.content,
        elapsed_ms=elapsed,
    )


def to_curl(req: ResolvedRequest) -> str:
    parts = ["curl", "-X", req.method, shlex.quote(full_url(req))]
    headers = dict(req.headers)
    if req.body.type == "json" and not any(k.lower() == "content-type" for k in headers):
        headers["Content-Type"] = "application/json"
    for key, value in headers.items():
        parts += ["-H", shlex.quote(f"{key}: {value}")]
    content = req.body.content
    if req.body.type == "json":
        parts += ["--data-raw", shlex.quote(json.dumps(content, ensure_ascii=False))]
    elif req.body.type == "text":
        parts += ["--data-raw", shlex.quote("" if content is None else str(content))]
    elif req.body.type == "form-urlencoded":
        for key, value in (content or {}).items():
            parts += ["--data-urlencode", shlex.quote(f"{key}={value}")]
    elif req.body.type == "multipart":
        for key, value in (content or {}).items():
            parts += ["-F", shlex.quote(f"{key}={value}")]
    return " ".join(parts)
```

```python
"""Aplicación de credenciales a un request resuelto."""

from __future__ import annotations

import base64
import time
from collections.abc import Callable
from dataclasses import dataclass, replace

import httpx

from kp9.model import AuthApiKey, AuthBasic, AuthBearer, AuthOAuth2CC
from kp9.resolve import ResolvedRequest

DEFAULT_TOKEN_TTL = 3600.0
REFRESH_MARGIN = 30.0
TokenKey = tuple[str, str, str]


class AuthError(Exception):
    def __init__(self, message: str, status: int | None = None, body: str = "") -> None:
        super().__init__(message)
        self.status = status
        self.body = body


@dataclass
class _CachedToken:
    value: str
    expires_at: float


class TokenCache:
    """Cache en memoria de tokens OAuth2; expira REFRESH_MARGIN s antes."""

    def __init__(self, clock: Callable[[], float] = time.monotonic) -> None:
        self._clock = clock
        self._tokens: dict[TokenKey, _CachedToken] = {}

    def get(self, key: TokenKey) -> str | None:
        token = self._tokens.get(key)
        if token is not None and token.expires_at > self._clock():
            return token.value
        return None

    def put(self, key: TokenKey, value: str, ttl: float) -> None:
        self._tokens[key] = _CachedToken(value, self._clock() + max(ttl - REFRESH_MARGIN, 0.0))

    def clear(self) -> None:
        self._tokens.clear()


def _set_header(headers: dict[str, str], name: str, value: str) -> None:
    for existing in [k for k in headers if k.lower() == name.lower()]:
        del headers[existing]
    headers[name] = value


async def fetch_token(auth: AuthOAuth2CC, client: httpx.AsyncClient, cache: TokenCache) -> str:
    key: TokenKey = (auth.tokenUrl, auth.clientId, " ".join(auth.scopes))
    cached = cache.get(key)
    if cached is not None:
        return cached
    form = {
        "grant_type": "client_credentials",
        "client_id": auth.clientId,
        "client_secret": auth.clientSecret,
    }
    if auth.scopes:
        form["scope"] = " ".join(auth.scopes)
    try:
        response = await client.post(auth.tokenUrl, data=form, headers={"Accept": "application/json"})
    except httpx.HTTPError as exc:
        raise AuthError(f"no se pudo contactar el token endpoint: {exc}") from exc
    if response.status_code >= 400:
        raise AuthError(
            f"token endpoint respondió {response.status_code}", response.status_code, response.text
        )
    try:
        payload = response.json()
        token = str(payload["access_token"])
    except (ValueError, KeyError, TypeError) as exc:
        raise AuthError(
            "respuesta del token endpoint sin access_token", response.status_code, response.text
        ) from exc
    try:
        ttl = float(payload.get("expires_in", DEFAULT_TOKEN_TTL))
    except (TypeError, ValueError):
        ttl = DEFAULT_TOKEN_TTL
    cache.put(key, token, ttl)
    return token


async def apply_auth(req: ResolvedRequest, client: httpx.AsyncClient, cache: TokenCache) -> ResolvedRequest:
    auth = req.auth
    headers = dict(req.headers)
    params = dict(req.params)
    if isinstance(auth, AuthBearer):
        _set_header(headers, "Authorization", f"Bearer {auth.token}")
    elif isinstance(auth, AuthBasic):
        raw = f"{auth.username}:{auth.password}".encode()
        _set_header(headers, "Authorization", "Basic " + base64.b64encode(raw).decode("ascii"))
    elif isinstance(auth, AuthApiKey):
        if auth.in_ == "query":
            params[auth.key] = auth.value
        else:
            _set_header(headers, auth.key, auth.value)
    elif isinstance(auth, AuthOAuth2CC):
        _set_header(headers, "Authorization", f"Bearer {await fetch_token(auth, client, cache)}")
    else:
        return req
    return replace(req, headers=headers, params=params)
```

```python
"""Historial de ejecuciones en SQLite (siempre redactado)."""

from __future__ import annotations

import json
import sqlite3
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path

from kp9.httpclient import Response, full_url
from kp9.redact import Redactor
from kp9.resolve import ResolvedRequest

_SCHEMA = """
CREATE TABLE IF NOT EXISTS executions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    ts TEXT NOT NULL,
    env TEXT,
    request_path TEXT,
    method TEXT NOT NULL,
    url TEXT NOT NULL,
    request_json TEXT NOT NULL,
    status INTEGER,
    reason TEXT,
    elapsed_ms REAL,
    response_headers TEXT,
    response_body BLOB,
    response_encoding TEXT,
    error TEXT
);
CREATE INDEX IF NOT EXISTS idx_executions_path ON executions (request_path, id);
"""


@dataclass(frozen=True)
class HistoryEntry:
    id: int
    ts: str
    env: str | None
    request_path: str | None
    method: str
    url: str
    request_json: str
    status: int | None
    reason: str | None
    elapsed_ms: float | None
    response_headers: list[tuple[str, str]]
    response_body: bytes | None
    response_encoding: str | None
    error: str | None

    def response(self) -> Response | None:
        if self.status is None:
            return None
        return Response(
            status=self.status,
            reason=self.reason or "",
            headers=self.response_headers,
            body=self.response_body or b"",
            elapsed_ms=self.elapsed_ms or 0.0,
            encoding=self.response_encoding,
        )


def _entry(row: sqlite3.Row) -> HistoryEntry:
    headers = json.loads(row["response_headers"]) if row["response_headers"] else []
    return HistoryEntry(
        id=row["id"],
        ts=row["ts"],
        env=row["env"],
        request_path=row["request_path"],
        method=row["method"],
        url=row["url"],
        request_json=row["request_json"],
        status=row["status"],
        reason=row["reason"],
        elapsed_ms=row["elapsed_ms"],
        response_headers=[(str(k), str(v)) for k, v in headers],
        response_body=row["response_body"],
        response_encoding=row["response_encoding"],
        error=row["error"],
    )


class History:
    def __init__(self, db_path: Path) -> None:
        db_path.parent.mkdir(parents=True, exist_ok=True)
        self._conn = sqlite3.connect(db_path)
        self._conn.row_factory = sqlite3.Row
        self._conn.executescript(_SCHEMA)

    def record(
        self,
        *,
        req: ResolvedRequest,
        response: Response | None,
        error: str | None,
        redactor: Redactor,
        env: str | None,
        request_path: str | None,
        now: datetime | None = None,
    ) -> int:
        ts = (now or datetime.now().astimezone()).isoformat(timespec="seconds")
        request_doc = {
            "method": req.method,
            "url": req.url,
            "params": req.params,
            "headers": dict(redactor.headers(req.headers)),
            "body": req.body.model_dump(mode="json"),
            "auth": {"type": req.auth.type},
        }
        request_json = json.dumps(redactor.value(request_doc), ensure_ascii=False, indent=2)
        status = reason = headers_json = encoding = None
        elapsed: float | None = None
        body: bytes | None = None
        if response is not None:
            status, reason, elapsed = response.status, response.reason, response.elapsed_ms
            headers_json = json.dumps(redactor.headers(response.headers), ensure_ascii=False)
            if response.is_binary:
                body = response.body
            else:
                body = redactor.text(response.text()).encode("utf-8")
                encoding = "utf-8"
        cursor = self._conn.execute(
            "INSERT INTO executions (ts, env, request_path, method, url, request_json, status, "
            "reason, elapsed_ms, response_headers, response_body, response_encoding, error) "
            "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)",
            (
                ts,
                env,
                request_path,
                req.method,
                redactor.text(full_url(req)),
                request_json,
                status,
                reason,
                elapsed,
                headers_json,
                body,
                encoding,
                redactor.text(error) if error else None,
            ),
        )
        self._conn.commit()
        return int(cursor.lastrowid or 0)

    def list(self, limit: int = 500) -> list[HistoryEntry]:
        rows = self._conn.execute(
            "SELECT * FROM executions ORDER BY id DESC LIMIT ?", (limit,)
        ).fetchall()
        return [_entry(r) for r in rows]

    def get(self, entry_id: int) -> HistoryEntry | None:
        row = self._conn.execute("SELECT * FROM executions WHERE id = ?", (entry_id,)).fetchone()
        return _entry(row) if row else None

    def last_for(self, request_path: str) -> HistoryEntry | None:
        row = self._conn.execute(
            "SELECT * FROM executions WHERE request_path = ? ORDER BY id DESC LIMIT 1",
            (request_path,),
        ).fetchone()
        return _entry(row) if row else None

    def close(self) -> None:
        self._conn.close()
```

```python
"""Importación de colecciones y entornos Postman v2.0/v2.1."""

from __future__ import annotations

import json
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, cast
from urllib.parse import parse_qsl

from kp9.model import (
    Auth,
    AuthApiKey,
    AuthBasic,
    AuthBearer,
    AuthInherit,
    AuthNone,
    AuthOAuth2CC,
    Body,
    CollectionMeta,
    Environment,
    FolderMeta,
    GroupMeta,
    HttpMethod,
    Request,
    SecretRef,
)
from kp9.secrets import load_secrets, save_secrets
from kp9.store import (
    COLLECTION_FILE,
    ENVIRONMENTS_DIR,
    FOLDER_FILE,
    GROUP_FILE,
    GROUPS_DIR,
    slugify,
    unique_path,
    write_json,
)

METHODS = frozenset({"GET", "POST", "PUT", "PATCH", "DELETE", "HEAD", "OPTIONS"})


class PostmanImportError(Exception):
    """El archivo no es importable."""


@dataclass
class ImportReport:
    target: Path | None = None
    requests: int = 0
    folders: int = 0
    environments: int = 0
    skipped: list[str] = field(default_factory=list)


def _s(value: Any) -> str:
    return "" if value is None else str(value)


def is_environment(data: Any) -> bool:
    return isinstance(data, dict) and "values" in data and "item" not in data


def _description(raw: Any) -> str:
    if isinstance(raw, dict):
        return _s(raw.get("content"))
    return _s(raw)


def _pairs(raw: Any) -> dict[str, str]:
    return {
        str(e["key"]): _s(e.get("value"))
        for e in raw or []
        if isinstance(e, dict) and e.get("key") and not e.get("disabled")
    }


def _variables(raw: Any) -> dict[str, str]:
    return _pairs(raw)


def _note_events(obj: dict[str, Any], report: ImportReport, label: str) -> None:
    for event in obj.get("event") or []:
        if not isinstance(event, dict):
            continue
        script = (event.get("script") or {}).get("exec")
        code = "\n".join(script) if isinstance(script, list) else _s(script)
        if code.strip():
            report.skipped.append(f"{label}: script '{event.get('listen', '?')}' omitido")


def _auth_values(raw: Any) -> dict[str, str]:
    if isinstance(raw, dict):
        return {str(k): _s(v) for k, v in raw.items()}
    if isinstance(raw, list):
        return {str(e["key"]): _s(e.get("value")) for e in raw if isinstance(e, dict) and "key" in e}
    return {}


def _auth(raw: Any, report: ImportReport, label: str) -> Auth | None:
    if not isinstance(raw, dict):
        return None
    kind = raw.get("type")
    values = _auth_values(raw.get(kind)) if isinstance(kind, str) else {}
    if kind == "noauth":
        return AuthNone()
    if kind == "bearer":
        return AuthBearer(token=values.get("token", ""))
    if kind == "basic":
        return AuthBasic(username=values.get("username", ""), password=values.get("password", ""))
    if kind == "apikey":
        return AuthApiKey.model_validate(
            {
                "type": "apikey",
                "key": values.get("key") or "X-Api-Key",
                "value": values.get("value", ""),
                "in": "query" if values.get("in") == "query" else "header",
            }
        )
    if kind == "oauth2":
        grant = values.get("grant_type", "?")
        if grant == "client_credentials":
            return AuthOAuth2CC(
                tokenUrl=values.get("accessTokenUrl", ""),
                clientId=values.get("clientId", ""),
                clientSecret=values.get("clientSecret", ""),
                scopes=values.get("scope", "").split(),
            )
        report.skipped.append(f"{label}: OAuth2 con grant '{grant}' no soportado")
        return None
    report.skipped.append(f"{label}: auth '{kind}' no soportada")
    return None


def _url(raw: Any) -> tuple[str, dict[str, str]]:
    if raw is None:
        return "", {}
    if isinstance(raw, str):
        text, query = raw, None
    else:
        text, query = _s(raw.get("raw")), raw.get("query")
    base, _, qs = text.partition("?")
    if query is not None:
        return base, _pairs(query)
    return base, dict(parse_qsl(qs, keep_blank_values=True))


def _body(raw: Any, report: ImportReport, label: str) -> tuple[Body, str | None]:
    """Devuelve (body, content-type a agregar si falta)."""
    if not isinstance(raw, dict) or raw.get("disabled"):
        return Body(), None
    mode = raw.get("mode")
    if mode == "raw":
        text = _s(raw.get("raw"))
        language = ((raw.get("options") or {}).get("raw") or {}).get("language")
        if language == "json":
            try:
                return Body(type="json", content=json.loads(text)), None
            except ValueError:
                report.skipped.append(
                    f"{label}: body JSON inválido (¿variables sin comillas?); importado como texto"
                )
                return Body(type="text", content=text), "application/json"
        return Body(type="text", content=text), None
    if mode == "urlencoded":
        return Body(type="form-urlencoded", content=_pairs(raw.get("urlencoded"))), None
    if mode == "formdata":
        fields: dict[str, str] = {}
        for entry in raw.get("formdata") or []:
            if not isinstance(entry, dict) or not entry.get("key") or entry.get("disabled"):
                continue
            key = str(entry["key"])
            if entry.get("type") == "file":
                src = entry.get("src")
                src = src[0] if isinstance(src, list) and src else src
                if not src:
                    report.skipped.append(f"{label}: campo de archivo '{key}' sin ruta")
                    continue
                fields[key] = f"@{src}"
            else:
                fields[key] = _s(entry.get("value"))
        return Body(type="multipart", content=fields), None
    if mode in (None, "none"):
        return Body(), None
    report.skipped.append(f"{label}: body '{mode}' no soportado")
    return Body(), None


def _request(item: dict[str, Any], name: str, report: ImportReport, label: str) -> Request | None:
    raw = item["request"]
    if isinstance(raw, str):
        raw = {"url": raw}
    if not isinstance(raw, dict):
        report.skipped.append(f"{label}: request inválido")
        return None
    method = _s(raw.get("method") or "GET").upper()
    if method not in METHODS:
        report.skipped.append(f"{label}: método {method} no soportado")
        return None
    url, params = _url(raw.get("url"))
    headers = _pairs(raw.get("header"))
    body, content_type = _body(raw.get("body"), report, label)
    if content_type and not any(k.lower() == "content-type" for k in headers):
        headers["Content-Type"] = content_type
    _note_events(item, report, label)
    auth = _auth(raw.get("auth"), report, label)
    return Request(
        name=name,
        description=_description(raw.get("description")),
        method=cast(HttpMethod, method),
        url=url,
        params=params,
        headers=headers,
        body=body,
        auth=auth or AuthInherit(),
    )


def _import_items(items: list[Any], directory: Path, report: ImportReport, trail: str) -> None:
    for item in items:
        if not isinstance(item, dict):
            continue
        name = _s(item.get("name")) or "sin-nombre"
        label = f"{trail}/{name}"
        if isinstance(item.get("item"), list):
            folder_dir = unique_path(directory, name)
            folder_dir.mkdir(parents=True)
            _note_events(item, report, label)
            write_json(
                folder_dir / FOLDER_FILE,
                FolderMeta(
                    name=name,
                    description=_description(item.get("description")),
                    auth=_auth(item.get("auth"), report, label),
                    variables=_variables(item.get("variable")),
                ),
            )
            report.folders += 1
            _import_items(item["item"], folder_dir, report, label)
        elif "request" in item:
            request = _request(item, name, report, label)
            if request is not None:
                write_json(unique_path(directory, name, ".json"), request)
                report.requests += 1
        else:
            report.skipped.append(f"{label}: ítem sin request ni carpeta")


def import_collection(data: Any, root: Path, group: str) -> ImportReport:
    if not isinstance(data, dict) or not isinstance(data.get("item"), list):
        raise PostmanImportError("el archivo no parece una colección Postman (falta 'item')")
    info = data.get("info") or {}
    schema = _s(info.get("schema"))
    if schema and "v2.0" not in schema and "v2.1" not in schema:
        raise PostmanImportError(f"versión de colección no soportada: {schema}")
    report = ImportReport()
    group_dir = root / GROUPS_DIR / slugify(group)
    if not (group_dir / GROUP_FILE).exists():
        write_json(group_dir / GROUP_FILE, GroupMeta(name=group))
    name = _s(info.get("name")) or "coleccion"
    col_dir = unique_path(group_dir, name)
    col_dir.mkdir(parents=True)
    _note_events(data, report, name)
    write_json(
        col_dir / COLLECTION_FILE,
        CollectionMeta(
            name=name,
            description=_description(info.get("description")),
            auth=_auth(data.get("auth"), report, name),
            variables=_variables(data.get("variable")),
        ),
    )
    _import_items(data["item"], col_dir, report, name)
    report.target = col_dir
    return report


def import_environment(data: Any, root: Path) -> ImportReport:
    if not is_environment(data) or not isinstance(data["values"], list):
        raise PostmanImportError("el archivo no parece un entorno Postman (falta 'values')")
    name = _s(data.get("name")) or "entorno"
    path = root / ENVIRONMENTS_DIR / f"{slugify(name)}.json"
    if path.exists():
        raise PostmanImportError(f"ya existe el entorno '{name}' en {path}")
    variables: dict[str, str | SecretRef] = {}
    env_secrets: dict[str, str] = {}
    for entry in data["values"]:
        if not isinstance(entry, dict) or not entry.get("key") or entry.get("enabled") is False:
            continue
        key = str(entry["key"])
        value = _s(entry.get("value"))
        if entry.get("type") == "secret":
            variables[key] = SecretRef(secret=True)
            env_secrets[key] = value
        else:
            variables[key] = value
    write_json(path, Environment(name=name, variables=variables))
    if env_secrets:
        secrets = load_secrets(root)
        secrets[name] = {**secrets.get(name, {}), **env_secrets}
        save_secrets(root, secrets)
    return ImportReport(target=path, environments=1)


def format_report(report: ImportReport) -> str:
    lines: list[str] = []
    if report.target:
        lines.append(f"Destino: {report.target}")
    if report.environments:
        lines.append(f"{report.environments} entorno(s) importado(s)")
    else:
        lines.append(f"{report.requests} requests importados en {report.folders} carpetas")
    if report.skipped:
        lines.append(f"Omitidos ({len(report.skipped)}):")
        lines += [f"  - {item}" for item in report.skipped]
    return "\n".join(lines)
```

```python
"""Línea de comandos de kp9."""

from __future__ import annotations

import json
from pathlib import Path
from typing import Annotated, Any

import typer

from kp9.importer.postman import (
    PostmanImportError,
    format_report,
    import_collection,
    import_environment,
)
from kp9.store import WorkspaceNotFound, find_workspace_root, init_workspace

app = typer.Typer(add_completion=False, help="kp9 — cliente HTTP para la terminal estilo k9s.")

WorkspaceOpt = Annotated[
    Path | None,
    typer.Option("--workspace", "-w", help="Carpeta del workspace (por defecto, la actual)."),
]


def _fail(message: str) -> typer.Exit:
    typer.echo(message, err=True)
    return typer.Exit(1)


def _root(workspace: Path | None) -> Path:
    try:
        return find_workspace_root(workspace or Path.cwd())
    except WorkspaceNotFound as exc:
        raise _fail(str(exc)) from exc


def _read_json(path: Path) -> Any:
    try:
        return json.loads(path.read_text(encoding="utf-8"))
    except OSError as exc:
        raise _fail(f"{path}: {exc.strerror}") from exc
    except json.JSONDecodeError as exc:
        raise _fail(f"{path}:{exc.lineno}:{exc.colno}: {exc.msg}") from exc


def _launch_tui(root: Path) -> None:
    from kp9.tui.app import Kp9App

    Kp9App(root).run()


@app.callback(invoke_without_command=True)
def main(ctx: typer.Context, workspace: WorkspaceOpt = None) -> None:
    """Sin subcomando abre la TUI."""
    if ctx.invoked_subcommand is None:
        _launch_tui(_root(workspace))


@app.command()
def init(
    path: Annotated[Path, typer.Argument(help="Carpeta del nuevo workspace.")] = Path("."),
    name: Annotated[str | None, typer.Option(help="Nombre del workspace.")] = None,
) -> None:
    """Crea la estructura base de un workspace."""
    try:
        root = init_workspace(path, name or path.resolve().name)
    except FileExistsError as exc:
        raise _fail(str(exc)) from exc
    typer.echo(f"Workspace creado en {root}")


@app.command("import")
def import_(
    file: Annotated[Path, typer.Argument(help="Colección Postman v2.1 (.json).")],
    group: Annotated[str, typer.Option("--group", "-g", help="Grupo destino.")],
    env: Annotated[
        list[Path] | None, typer.Option("--env", "-e", help="Entorno Postman (repetible).")
    ] = None,
    workspace: WorkspaceOpt = None,
) -> None:
    """Importa una colección (y entornos opcionales) de Postman."""
    root = _root(workspace)
    try:
        reports = [import_collection(_read_json(file), root, group)]
        for env_file in env or []:
            reports.append(import_environment(_read_json(env_file), root))
    except PostmanImportError as exc:
        raise _fail(str(exc)) from exc
    for report in reports:
        typer.echo(format_report(report))
```

```python
"""Orquestación de un envío: resolver → autenticar → enviar → registrar."""

from __future__ import annotations

import asyncio
import os
from collections.abc import Mapping
from dataclasses import dataclass
from pathlib import Path

import httpx

from kp9.auth import AuthError, TokenCache, apply_auth
from kp9.history import History
from kp9.httpclient import RequestFailed, Response, send
from kp9.model import Environment
from kp9.redact import Redactor
from kp9.resolve import ResolvedRequest, resolve
from kp9.secrets import SecretsError, env_values, load_secrets, sensitive_values
from kp9.store import RequestNode, Workspace

SAFE_METHODS = frozenset({"GET", "HEAD", "OPTIONS"})
CANCELLED = "cancelado"


class NotSendable(Exception):
    """El request no puede prepararse (archivo inválido, secrets.json roto)."""


@dataclass(frozen=True)
class SendOutcome:
    resolved: ResolvedRequest
    response: Response | None
    error: str | None
    history_id: int


class Runner:
    def __init__(
        self,
        workspace: Workspace,
        history: History,
        client: httpx.AsyncClient,
        cache: TokenCache | None = None,
        environ: Mapping[str, str] | None = None,
    ) -> None:
        self.workspace = workspace
        self.history = history
        self.client = client
        self.cache = cache or TokenCache()
        self._environ: Mapping[str, str] = os.environ if environ is None else environ

    def environment(self, env_name: str | None) -> Environment | None:
        return self.workspace.environments.get(env_name) if env_name else None

    def _values(self, env_name: str | None) -> tuple[dict[str, str], list[str]]:
        env = self.environment(env_name)
        try:
            secrets = load_secrets(self.workspace.root)
        except SecretsError as exc:
            raise NotSendable(str(exc)) from exc
        return (
            env_values(env, secrets, self._environ),
            sensitive_values(env, secrets, self._environ),
        )

    def redactor(self, env_name: str | None) -> Redactor:
        _, sensitive = self._values(env_name)
        return Redactor(sensitive, self.workspace.config.redactHeaders)

    def prepare(self, node: RequestNode, env_name: str | None) -> ResolvedRequest:
        if node.request is None:
            raise NotSendable(node.error or f"{node.path}: request inválido")
        values, _ = self._values(env_name)
        return resolve(node.request, node.chain, values, env_name)

    def needs_confirmation(self, resolved: ResolvedRequest, env_name: str | None) -> bool:
        env = self.environment(env_name)
        return bool(env and env.protected and resolved.method not in SAFE_METHODS)

    async def authorize(self, resolved: ResolvedRequest) -> ResolvedRequest:
        return await apply_auth(resolved, self.client, self.cache)

    async def execute(
        self, resolved: ResolvedRequest, env_name: str | None, request_path: Path | None
    ) -> SendOutcome:
        redactor = self.redactor(env_name)
        rel = request_path.relative_to(self.workspace.root).as_posix() if request_path else None
        sent = resolved
        response: Response | None = None
        error: str | None = None
        try:
            sent = await self.authorize(resolved)
            response = await send(sent, self.client, self.workspace.config.timeout)
        except AuthError as exc:
            error = f"{exc}\n{exc.body}" if exc.body else str(exc)
        except RequestFailed as exc:
            error = f"{exc.kind}: {exc}"
        except asyncio.CancelledError:
            self.history.record(
                req=sent, response=None, error=CANCELLED, redactor=redactor,
                env=env_name, request_path=rel,
            )
            raise
        safe_error = redactor.text(error) if error else None
        history_id = self.history.record(
            req=sent, response=response, error=safe_error, redactor=redactor,
            env=env_name, request_path=rel,
        )
        return SendOutcome(resolved, response, safe_error, history_id)
```

```python
def status_style(status: int) -> str:
    if status < 300:
        return "bold green"
    if status < 400:
        return "bold cyan"
    if status < 500:
        return "bold yellow"
    return "bold red"


def human_size(n: int) -> str:
    if n < 1024:
        return f"{n} B"
    if n < 1024 * 1024:
        return f"{n / 1024:.1f} KB"
    return f"{n / (1024 * 1024):.1f} MB"


def last_text(entry: HistoryEntry | None) -> Text:
    if entry is None:
        return Text("—", style="dim")
    if entry.status is None:
        return Text("✗ error", style="bold red")
    return Text(f"{entry.status} · {entry.elapsed_ms or 0:.0f}ms", style=status_style(entry.status))


def mark(name: str, error: str | None) -> Text:
    return Text(f"⚠ {name}", style="bold red") if error else Text(name)
```

```python
"""Bases de las vistas apilables. Regla: solo View define on_mount."""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path
from typing import TYPE_CHECKING, Any, cast

from rich.markup import escape
from rich.text import Text
from textual.app import ComposeResult
from textual.containers import Vertical
from textual.widgets import DataTable

if TYPE_CHECKING:
    from kp9.tui.app import Kp9App

Cell = str | Text


@dataclass
class Row:
    key: str
    cells: tuple[Cell, ...]
    target: Any


class View(Vertical):
    """Una vista de recursos. Las subclases personalizan setup()/reload()."""

    @property
    def kp9(self) -> Kp9App:
        return cast("Kp9App", self.app)

    @property
    def crumb(self) -> str:
        return "?"

    @property
    def group_path(self) -> Path | None:
        return None

    @property
    def has_filter(self) -> bool:
        return False

    def setup(self) -> None:
        """Se llama una vez al montar, antes del primer reload()."""

    def reload(self) -> None:
        """Vuelve a leer los datos desde self.kp9.workspace."""

    def apply_filter(self, text: str) -> None:
        """Filtra el contenido visible."""

    def focus_default(self) -> None:
        self.focus()

    def cancel(self) -> bool:
        """Cancela trabajo en curso; True si había algo que cancelar."""
        return False

    def on_mount(self) -> None:
        self.setup()
        self.reload()
        if self.kp9.current is self:
            self.focus_default()


class TableView(View):
    COLUMNS: tuple[str, ...] = ()

    def __init__(self) -> None:
        super().__init__()
        self._rows: list[Row] = []
        self._by_key: dict[str, Row] = {}
        self._filter = ""

    def compose(self) -> ComposeResult:
        yield DataTable(cursor_type="row", id="table")

    @property
    def table(self) -> DataTable[Cell]:
        return cast("DataTable[Cell]", self.query_one("#table", DataTable))

    def setup(self) -> None:
        self.table.add_columns(*self.COLUMNS)

    def heading(self) -> str:
        raise NotImplementedError

    def rows(self) -> list[Row]:
        raise NotImplementedError

    def open(self, row: Row) -> None:
        """Acción de Enter sobre una fila."""

    @property
    def has_filter(self) -> bool:
        return bool(self._filter)

    def visible_rows(self) -> list[Row]:
        if not self._filter:
            return list(self._rows)
        needle = self._filter.lower()
        return [r for r in self._rows if any(needle in str(c).lower() for c in r.cells)]

    def selected(self) -> Row | None:
        table = self.table
        if table.row_count == 0:
            return None
        key = table.coordinate_to_cell_key(table.cursor_coordinate).row_key.value
        return self._by_key.get(key) if key is not None else None

    def reload(self) -> None:
        current = self.selected()
        self._rows = self.rows()
        self._by_key = {r.key: r for r in self._rows}
        self._show(current.key if current else None)

    def apply_filter(self, text: str) -> None:
        current = self.selected()
        self._filter = text.strip()
        self._show(current.key if current else None)

    def _show(self, keep_key: str | None) -> None:
        table = self.table
        table.clear()
        visible = self.visible_rows()
        for row in visible:
            table.add_row(*row.cells, key=row.key)
        title = f"{self.heading()}[{len(visible)}]"
        if self._filter:
            title += f" </{self._filter}>"
        self.border_title = escape(title)
        if keep_key is not None and any(r.key == keep_key for r in visible):
            table.move_cursor(row=table.get_row_index(keep_key))

    def focus_default(self) -> None:
        self.table.focus()

    def on_data_table_row_selected(self, event: DataTable.RowSelected) -> None:
        event.stop()
        key = event.row_key.value
        row = self._by_key.get(key) if key is not None else None
        if row is not None:
            self.open(row)
```

```python
class RequestsView(TableView):
    COLUMNS = ("METHOD", "NAME", "URL", "LAST")

    def __init__(self, container_path: Path) -> None:
        super().__init__()
        self.container_path = container_path

    @property
    def group_path(self) -> Path | None:
        return group_dir_of(self.kp9.root, self.container_path)

    @property
    def crumb(self) -> str:
        return self.container_path.name

    def heading(self) -> str:
        rel = self.container_path.relative_to(self.kp9.root / GROUPS_DIR).as_posix()
        return f"Requests({rel})"

    def _container(self) -> ContainerNode | None:
        node = self.kp9.workspace.node_at(self.container_path)
        return node if isinstance(node, ContainerNode) else None

    def rows(self) -> list[Row]:
        node = self._container()
        if node is None:
            return []
        out: list[Row] = []
        for folder in node.children:
            cells = (Text("▸", style="bold"), mark(f"{folder.name}/", folder.error), Text(""), Text(""))
            out.append(Row(str(folder.path), cells, folder))

            else:
                cells = (Text("?"), mark(req.name, req.error), Text(req.error or ""), last)
            out.append(Row(str(req.path), cells, req))
        return out

    def open(self, row: Row) -> None:

        if isinstance(target, ContainerNode):
```

```python
        return tuple(self._stack)

        self._stack.append(view)
        self.query_one("#body", Vertical).mount(view)
        self.refresh_chrome()

    def pop_view(self) -> bool:
        if len(self._stack) <= 1:
            return False
        self._stack.pop().remove()
        previous = self._stack[-1]
        previous.display = True
        previous.reload()
        previous.focus_default()
        self.refresh_chrome()
        return True

        for view in self._stack:
            view.remove()
        self._stack.clear()
        for view in views:
            self.push_view(view)

        return path.relative_to(self.root).as_posix()

    @property
    def current_group(self) -> Path | None:
        for view in reversed(self._stack):
            group = view.group_path
            if group is not None:
                self._last_group = group
                return group
        return self._last_group

    def _default_group(self) -> Path | None:
        name = self.workspace.config.defaultGroup
        if not name:
            return None
        path = self.root / GROUPS_DIR / slugify(name)
        return path if isinstance(self.workspace.node_at(path), ContainerNode) else None

    def _initial_env(self) -> str | None:
        envs = self.workspace.environments
        default = self.workspace.config.defaultEnv
        if default in envs:
            return default
        return sorted(envs)[0] if envs else None

            return False
        self.env_name = name
        self.refresh_chrome()
        if self.current is not None:
            self.current.reload()
        self.notify(f"entorno activo: {name}")
        return True

        protected = bool(env and env.protected)
        group_path = self.current_group
        group = self.workspace.node_at(group_path) if group_path else None
        group_name = group.name if isinstance(group, ContainerNode) else "—"
        env_label = f"<{self.env_name}>" if self.env_name else "<sin entorno>"
        if protected:
            env_label += " PROTEGIDO"
        self.topbar_text = (
            f"Workspace: {self.workspace.config.name}   Env: {env_label}   Grupo: {group_name}"
            f"\n{SHORTCUTS}"
        )
        topbar = self.query_one("#topbar", Static)
        topbar.update(Text(self.topbar_text))
        topbar.set_class(protected, "protected")
        self.crumbs_text = " ".join(f"<{view.crumb}>" for view in self._stack)
        self.query_one("#crumbs", Static).update(Text(self.crumbs_text))

    def reload_workspace(self) -> None:
        try:
            workspace = load_workspace(self.root)
        except WorkspaceNotFound as exc:
            self.notify(str(exc), severity="error")
            return
        self.workspace = workspace
        self.runner.workspace = workspace
        if self.env_name and self.env_name not in workspace.environments:
            self.notify(
                f"el entorno '{self.env_name}' ya no existe; sin entorno activo", severity="warning"
            )
            self.env_name = None
        for view in self._stack:
            view.reload()
        self.refresh_chrome()

    # ---- prompt (se completa en Task 13) ---------------------------------

    def close_prompt(self) -> None:
        self._prompt_mode = None
        prompt = self.query_one("#prompt", Input)
        prompt.value = ""
        prompt.display = False
        if self.current is not None:
            self.current.focus_default()

    # ---- acciones -------------------------------------------------------

        self.reset_to(GroupsView())

    def action_goto_collections(self) -> None:
        group = self.current_group or self._default_group()
        if group is None:
            self.notify(
                "Abre un grupo primero (o define defaultGroup en workspace.json)",
                severity="warning",
            )
            return
        self.reset_to(GroupsView(), CollectionsView(group))

    def action_back(self) -> None:
        if self.query_one("#prompt", Input).display:
            self.close_prompt()
            return
        view = self.current
        if view is None:
            return
        if view.cancel():
            return
        if view.has_filter:
            view.apply_filter("")
            return
        self.pop_view()
```

```python
        self.error_text = message
        self.status_text = "error"
        self.headers_text = self.body_text = ""
        self._paint(Text(f"✗ {message}", style="bold red"), "", Text(""))

    def show_response(self, response: Response) -> None:
        self._response = response
        self.error_text = ""
        self.status_text = (
            f"{response.status} {response.reason} · {response.elapsed_ms:.0f} ms · "
            f"{human_size(response.size)}"
        )
        self.headers_text = "\n".join(f"{k}: {v}" for k, v in response.headers)
        self._refresh_body()

    def set_filter(self, text: str) -> None:
        self.filter_text = text.strip()
        self._refresh_body()

    def _refresh_body(self) -> None:
        response = self._response
        if response is None:
            return
        text = response.pretty()
        truncated = len(text) > MAX_BODY_CHARS
        if truncated:
            text = text[:MAX_BODY_CHARS]
        if self.filter_text:
            needle = self.filter_text.lower()
            text = "\n".join(line for line in text.splitlines() if needle in line.lower())
        if truncated:
            text += (
                f"\n… respuesta truncada ({human_size(response.size)} en total; "
                "y copia el body completo)"
            )
        self.body_text = text
        body: Text | Syntax
        if response.is_json and not truncated and not self.filter_text:
            body = Syntax(text, "json", word_wrap=True, background_color="default")
        else:
            body = Text(text)
        self._paint(Text(self.status_text, style=status_style(response.status)), self.headers_text, body)
```

```python
    BINDINGS = [
        Binding("s", "send", "enviar"),
        Binding("ctrl+r", "send", "enviar", show=False),
        Binding("c", "copy_curl", "copiar curl"),
        Binding("y", "copy_body", "copiar body"),
    ]

    def __init__(self, request_path: Path, *, autosend: bool = False) -> None:
        super().__init__()
        self.request_path = request_path
        self.summary_text = ""
        self._autosend = autosend
        self._worker: Worker[None] | None = None

    def compose(self) -> ComposeResult:
        yield Static(id="summary")
        with TabbedContent(id="tabs"):
            for label in TABS:
                with TabPane(label, id=f"tab-{label.lower()}"):
                    yield Static(id=f"def-{label.lower()}")
        yield ResponsePanel(id="response")

    @property
    def panel(self) -> ResponsePanel:
        return self.query_one("#response", ResponsePanel)

    @property
    def crumb(self) -> str:
        return self.request_path.stem

    @property
    def group_path(self) -> Path | None:
        return group_dir_of(self.kp9.root, self.request_path)

    @property
    def in_flight(self) -> bool:
        return self._worker is not None and self._worker.is_running

    @property
    def has_filter(self) -> bool:
        return bool(self.panel.filter_text)

    def apply_filter(self, text: str) -> None:
        self.panel.set_filter(text)

    def node(self) -> RequestNode | None:
        node = self.kp9.workspace.node_at(self.request_path)
        return node if isinstance(node, RequestNode) else None

    def setup(self) -> None:
        if self._autosend:
            self.call_after_refresh(self.action_send)

    def reload(self) -> None:
        self.border_title = escape(f"Detalle({self.kp9.rel(self.request_path)})")
        summary = self.query_one("#summary", Static)
        node = self.node()
        if node is None or node.request is None:
            message = node.error if node is not None else "el request ya no existe"
            self.summary_text = f"⚠ {message}"
            summary.update(Text(self.summary_text, style="bold red"))
            return
        req = node.request
        self.summary_text = f"{req.method}  {req.url}"
        if req.description:
            self.summary_text += f"\n{req.description}"
        summary.update(Text.assemble(method_text(req.method), f"  {req.url}",
                                     f"\n{req.description}" if req.description else ""))
        self.query_one("#def-params", Static).update(_json_view(req.params))
        self.query_one("#def-headers", Static).update(_json_view(req.headers))
        self.query_one("#def-body", Static).update(_json_view(dump(req.body)))
        self.query_one("#def-auth", Static).update(_json_view(dump(req.auth)))

    # ---- envío ----------------------------------------------------------

    def _fail(self, message: str) -> None:
        self.panel.show_error(message)
        self.kp9.notify(f"{message}\n(E: entornos)", title="no se envió", severity="error")

    def _prepare(self) -> ResolvedRequest | None:
        node = self.node()
        if node is None:
            self._fail("el request ya no existe")
            return None
        try:
            return self.kp9.runner.prepare(node, self.kp9.env_name)
        except (ResolveError, NotSendable) as exc:
            self._fail(str(exc))
            return None

    def action_send(self) -> None:
        if self.in_flight:
            return
        resolved = self._prepare()
        if resolved is None:
            return
        env = self.kp9.env_name
        if self.kp9.runner.needs_confirmation(resolved, env):
            question = f"El entorno '{env}' está protegido.\n¿Enviar {resolved.method} {resolved.url}?"
            self.kp9.push_screen(
                ConfirmScreen(question), lambda ok: self._start(resolved) if ok else None
            )
        else:
            self._start(resolved)

    def _start(self, resolved: ResolvedRequest) -> None:
        self.panel.show_pending()
        self._worker = self.run_worker(self._send(resolved), exclusive=True, group="send")

    async def _send(self, resolved: ResolvedRequest) -> None:
        outcome = await self.kp9.runner.execute(resolved, self.kp9.env_name, self.request_path)
        if outcome.response is not None:
            self.panel.show_response(outcome.response)
        else:
            self.panel.show_error(outcome.error or "error desconocido")

    def cancel(self) -> bool:
        if self._worker is not None and self._worker.is_running:
            self._worker.cancel()
            self.panel.show_error("cancelado")
            return True
        return False

    # ---- copiar ---------------------------------------------------------

    def action_copy_curl(self) -> None:
        resolved = self._prepare()
        if resolved is not None:
            self.run_worker(self._copy_curl(resolved), group="curl")

    async def _copy_curl(self, resolved: ResolvedRequest) -> None:
        try:
            authed = await self.kp9.runner.authorize(resolved)
        except AuthError as exc:
            self.kp9.notify(str(exc), severity="error")
            return
        self.kp9.copy_to_clipboard(to_curl(authed))
        self.kp9.notify("request copiado como curl")

    def action_copy_body(self) -> None:
        response = self.panel.current_response
        if response is None:
            self.kp9.notify("no hay respuesta para copiar", severity="warning")
            return
        self.kp9.copy_to_clipboard(response.pretty())
        self.kp9.notify("body copiado")
```

```python
    # ---- prompt y comandos ----------------------------------------------

    def _command_suggestions(self) -> list[str]:
        out = ["groups", "history", "env", "import ", "q"]
        out += [f"env {name}" for name in sorted(self.workspace.environments)]
        out += [f"col {c.path.name}" for g in self.workspace.groups for c in g.children]
        return out

    def action_prompt(self, mode: str) -> None:
        prompt = self.query_one("#prompt", Input)
        self._prompt_mode = mode
        prompt.suggester = (
            SuggestFromList(self._command_suggestions(), case_sensitive=False) if mode == ":" else None
        )
        prompt.placeholder = "comando…" if mode == ":" else "filtro…"
        prompt.value = ""
        prompt.display = True
        prompt.focus()

    def close_prompt(self) -> None:
        self._prompt_mode = None
        prompt = self.query_one("#prompt", Input)
        prompt.value = ""
        prompt.display = False
        if self.current is not None:
            self.current.focus_default()

    def on_input_changed(self, event: Input.Changed) -> None:
        if event.input.id == "prompt" and self._prompt_mode == "/" and self.current is not None:
            self.current.apply_filter(event.value)

    def on_input_submitted(self, event: Input.Submitted) -> None:
        if event.input.id != "prompt":
            return
        event.stop()
        mode, value = self._prompt_mode, event.value
        self.close_prompt()
        if mode == ":":
            self.run_command(value)
        elif mode == "/" and self.current is not None:
            self.current.apply_filter(value)

    def _find_collection(self, name: str) -> ContainerNode | None:
        needle = name.strip().lower()
        current = self.current_group
        groups = sorted(self.workspace.groups, key=lambda g: g.path != current)
        for group in groups:
            for col in group.children:
                if needle in (col.path.name.lower(), col.name.lower()):
                    return col
        return None

    def run_command(self, text: str) -> None:
        command, _, arg = text.strip().partition(" ")
        arg = arg.strip()
        if command in ("q", "quit"):
            self.exit()
        elif command == "groups":
            self.action_goto_groups()
        elif command == "history":
            self.action_goto_history()
        elif command == "env":
            if arg:
                self.set_env(arg)
            else:
                self.action_goto_envs()
        elif command == "col":
            col = self._find_collection(arg)
            if col is None:
                self.notify(f"colección '{arg}' no encontrada", severity="error")
                return
            self.reset_to(GroupsView(), CollectionsView(col.path.parent), RequestsView(col.path))
        elif command:
            self.notify(f"comando desconocido: {command}", severity="error")

    def rerun(self, entry: HistoryEntry) -> None:
        if not entry.request_path:
            self.notify("la ejecución no está asociada a un archivo de request", severity="error")
            return
        path = self.root / entry.request_path
        if not isinstance(self.workspace.node_at(path), RequestNode):
            self.notify(f"{entry.request_path} ya no existe", severity="error")
            return
        if entry.env != self.env_name:
            self.notify(f"se re-ejecuta con el entorno activo ({self.env_name or 'ninguno'})")
        self.push_view(DetailView(path, autosend=True))
```

```python
    # ---- archivos -------------------------------------------------------

    def edit_file(self, path: Path) -> None:
        try:
            editor.open_in_editor(self, path)
        except FileNotFoundError:
            self.notify(f"no se encontró el editor '{editor.editor_command()[0]}'", severity="error")
            return
        except SuspendNotSupported:
            self.notify("este terminal no permite abrir el editor", severity="error")
            return
        self.reload_workspace()
        _, error = read_model(path, model_for_file(self.root, path))
        if error:
            self.push_screen(
                ConfirmScreen(f"{error}\n\n¿Reabrir el editor?"),
                lambda ok: self.edit_file(path) if ok else None,
            )

    def delete_path(self, path: Path) -> None:
        if path.is_dir():
            shutil.rmtree(path)
        elif path.exists():
            path.unlink()
        self.reload_workspace()
        self.notify(f"borrado: {self.rel(path)}")

    def _import_group(self) -> str | None:
        group = self.current_group
        if group is not None:
            return group.name
        return self.workspace.config.defaultGroup

    def import_file(self, arg: str) -> None:
        if not arg:
            self.notify("uso: :import <archivo>", severity="error")
            return
        path = Path(arg).expanduser()
        if not path.is_absolute():
            path = Path.cwd() / path
        try:
            data = json.loads(path.read_text(encoding="utf-8"))
        except OSError as exc:
            self.notify(f"{path}: {exc.strerror}", severity="error")
            return
        except json.JSONDecodeError as exc:
            self.notify(f"{path}:{exc.lineno}:{exc.colno}: {exc.msg}", severity="error")
            return
        try:
            if is_environment(data):
                report = import_environment(data, self.root)
            else:
                group = self._import_group()
                if group is None:
                    self.notify(
                        "abre un grupo o define defaultGroup en workspace.json", severity="error"
                    )
                    return
                report = import_collection(data, self.root, group)
        except PostmanImportError as exc:
            self.notify(str(exc), severity="error")
            return
        self.reload_workspace()
        self.notify(format_report(report), title="importación", timeout=10)
```
